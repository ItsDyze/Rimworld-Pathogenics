# Roadmap

This folder tracks features as small, focused markdown files.

## Planned

Features that are designed or intended but not yet implemented.

## Done

Features that have been implemented, deprecated, or intentionally replaced.

## Workflow

1. Create a feature file in `Planned`.
2. Implement the feature.
3. Update the feature status and acceptance criteria.
4. Move the file to `Done`.

## Naming convention

Use numbered, kebab-case filenames:

```text
001-standalone-respiratory-disease.md
002-hidden-disease-state.md
003-exposure-accumulation.md
```

The number represents the intended implementation order.

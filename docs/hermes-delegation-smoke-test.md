# Hermes Delegation Smoke Test

This document outlines the delegation model between Hermes and OpenHands agents.

## Agent Roles

- **Hermes**: Acts as the manager agent, orchestrating tasks and delegating work.
- **OpenHands**: Acts as the worker agent, executing delegated tasks.

## Credentials

GitHub App credentials are used for branch and pull request operations.

## Workflow

Human review is required before any merge is performed.

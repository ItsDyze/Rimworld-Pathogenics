# Dyze Core Example

A RimWorld tutorial mod built step by step.
Is it AI-assisted? Of course.

## Target version

RimWorld 1.6

## Scope

This mod is used to learn:

- Mod structure
- XML Defs
- XML patches
- Textures
- Localization
- C# assemblies
- Harmony patches
- Compatibility practices

## Design principles

- Prefer XML before C#.
- Prefer patches before overwrites.
- Keep packageId stable.
- Keep Def names unique.
- Test changes in small increments.
